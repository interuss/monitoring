# uss_qualifier Test Run Report Artifacts

This directory contains the artifacts generated from a uss_qualifier test run.

## Artifacts Layout:
- **`report.json`**: The raw TestRunReport.
- **Tested Requirements Views**: Summary of tested requirements per participant:
  - `gate3/`: Contains HTML compliance reports and `status.json` for participant verifications.
- **`sequence/`**: Chronological log of events and scenarios.
- **`timing/`**: Test execution timing details.
- **`globally_expanded/`**: Mimics manual test run logs.
